# AGENTS.md: Civilization V Mod Manager (ui/)

Guidelines for anyone (human or AI) working on this app. Read README.md first for architecture and the manifest format.

## Golden rules

1. **Never touch the real game from tests or scripts.** Tests use temp folders from `tests/helpers.ts` (`tmp()`, `makeGame()`). `npm run smoke` reads the real install read-only. The app never writes to the game on its own: startup is read-only, and `switchTo` runs only on a user click. Don't add automatic installs/restores. Running `npm run dev` is the user's decision; agents don't run it (or `switchTo`) against a real installation unless asked. Never start Civilization V.
2. **Data safety beats features.** Any new code that writes or deletes in the game folder must go through `ModEngine` and keep its invariants:
   - only paths from a manifest or our own state/journal are touched;
   - every path goes through `resolveInside()`;
   - back up (and verify by hash) before overwriting;
   - delete only files whose hash matches what we installed;
   - journal before changing;
   - roll back on failure.
3. **Filesystem work stays in the main process.** The renderer only uses `window.civ5mm` (`src/preload/index.ts`). Never expose `ipcRenderer`, `fs` or path-taking calls. Keep `contextIsolation`, `sandbox`, `nodeIntegration: false` and the CSP.
4. **No mod-specific logic in the engine.** Mod differences belong in `mods/<id>/mod.source.json` / `manifest.json`. Vanilla is the baseline, not a mod.

## Layout

- `src/main/core/**`: plain Node + TypeScript, no `electron` imports, so it stays unit-testable.
- `src/main/index.ts`: the Electron wiring only.
- `src/shared/types.ts`: the IPC contract; change it together with preload and renderer.
- `mods/*/payload`, `mods/*/originals`: generated by `npm run payload` and git-ignored. Don't edit them by hand. `manifest.json` is generated too, but committed.

## Workflow

```bash
npm install
npm run typecheck && npm test     # must pass before committing
npm run dev                       # rebuild the mod + install it into the real game (user's decision)
npm run smoke                     # headless read-only check against the detected game (screenshot in /tmp)
```

- Add a test for every engine/detection change: success, repeat (idempotency), failure plus rollback (use `faultyFs()`), and "doesn't touch foreign files".
- User-facing errors are `UserError` with a sentence that says what happened and what to do. Map errno codes in `describeFsError`.
- Keep the UI simple and functional; visual design comes later.
- Pin nothing to old versions without a reason; keep Electron, Vite, React and TypeScript on current stable releases.
